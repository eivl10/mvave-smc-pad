# M-Vave SMC-PAD Windows Bridge

**EN.** Windows desktop app that connects the M-Vave SMC-PAD Bluetooth MIDI controller directly over BLE (no MIDI drivers) and maps its 16 pads, 8 endless knobs and 8 buttons to PC actions: volume with an on-screen indicator, media, windows, virtual desktops, browser, custom hotkeys, launching programs, pad colours and monitor brightness. Shows the controller's battery level. Settings export to a file and import on another PC. Lives in the system tray. Python 3 + CustomTkinter + bleak.

**Easiest:** download `SMC-PAD.exe` from [Releases](https://github.com/eivl10/mvave-smc-pad/releases) — no Python needed. Or from source:

```bash
pip install -r requirements.txt
pythonw midi_gui.py
```

---

Программа для прямого подключения Bluetooth MIDI-контроллера M-Vave SMC-PAD к Windows и привязки его пэдов, энкодеров и кнопок к системным действиям.

## Зачем это существует
По умолчанию Windows не видит BLE MIDI устройства как стандартные системные MIDI-порты (требуются специальные UWP-драйверы, которые не всегда работают или ставятся из-за UAC). Эта программа обходит проблему, подключаясь напрямую к GATT-характеристикам устройства по Bluetooth LE. Она перехватывает RAW MIDI пакеты, декодирует их (включая сложные дельты бесконечных энкодеров) и позволяет через графический интерфейс привязать любые контроллы к управлению громкостью, скроллом, медиа-кнопками, кастомными хоткеями или запуску скриптов.

## Исходное ТЗ
Пользователь просил создать программу для работы с M-Vave SMC-PAD по Bluetooth, так как устройство не работало корректно через стандартные драйверы. Нужно было реализовать плавную регулировку громкости с кнобов (бесконечных энкодеров), правильное отображение интерфейса (пэды, кнопки, кнобы), управление цветами пэдов и возможность биндить системные действия.

## Что умеет
- **Прямое BLE подключение**: работает без установки сторонних виртуальных MIDI-драйверов, авто-реконнект.
- **Умный декодер кнобов (Endless Encoders)**: корректно обрабатывает Two's Complement и Centered-64 форматы, защищая от резких скачков значений.
- **Громкость через системный микшер**: уровень пишется напрямую в `IAudioEndpointVolume` (pycaw), шаг 1% на щелчок энкодера. Медиа-клавиши остались запасным путём на случай, если pycaw недоступен.
- **Свой индикатор громкости**: системный флайаут Windows появляется только в ответ на нажатие медиа-клавиши, а прямая запись в микшер его не вызывает — поэтому у приложения собственная плашка, повторяющая системную по геометрии, шрифтам и цветам.
- **Визуальный маппинг**: GUI повторяет физическую раскладку устройства (пэды 4x4 по стандарту MPC, кнобы, кнопки).
- **Восемь банков пэдов**: назначения общие между банками, банк определяется по диапазону входящей ноты.
- **Привязка задним числом**: нажал незнакомый элемент — потом повесил на него действие, не ловя момент нажатия.
- **Раздельные действия на вращение** крутилки влево и вправо. Замок между сторонами: выбрал «следующий трек» — на другую сторону встал «предыдущий»; у действия без пары замок открывается сам.
- **Гладкая отрисовка**: скругления и крутилки сглажены (PIL с запасом ×4) — на Windows Tk рисует их ступеньками.
- **Автозапуск с Windows** из меню настроек: окно стартует спрятанным в трей. Там же — ярлык на рабочем столе. Работает и в exe.
- **Справка** — кнопка «i» в шапке. Имена элементов латиницей: PAD 6, KNOB 6, BUTTON. «Выбор нажатием» подсвечивает нажатый контрол, не выполняя действие.
- **Окно помнит размер и место**; минимальная высота считается от содержимого, окно не выходит за рабочую область.
- **Цвета и яркость пэдов**: отправка цвета на железо, общий фейдер яркости всех 16 пэдов.
- **Яркость монитора** через внешнюю программу автора DimTray — по именованному каналу Windows, а не горячими клавишами. DimTray в репозиторий не входит; без неё эти действия просто сообщают, что она не запущена.
- **Живёт в трее**: крестик и сворачивание прячут окно в значок у часов, клик по значку возвращает, выход — пунктом «Выход» в его меню. Второй запуск не плодит копию, а показывает окно уже работающей.
- **Пресеты**: «Настройки → Сохранить как пресет» и «Пресеты» — список сохранённых настроек прямо в программе, открыть или удалить (в Корзину) без выбора файла. Лежат в папке `presets/` рядом с программой.
- **Перенос настроек**: «Экспорт в файл» — одним JSON все назначения, цвета, яркость и свои цвета палитры. На другом компьютере «Импорт из файла»: файл сразу попадает в пресеты, перед заменой текущие настройки копируются в `presets/_backups`, адрес контроллера и тема не переносятся, а пути к программам, которых на новой машине нет, перечисляются в отчёте.
- **Тёмная и светлая тема**, переключатель в меню настроек (как в Windows / тёмная / светлая). Свои уведомления и окна вместо системных.
- **Своя палитра**: цвет из окна выбора остаётся кружком в палитре, правый клик убирает.
- **Заряд контроллера** в шапке: читается из Battery Service `180F/2A19`, обновляется сам.
- **BT, PAD BANK, KNOB BANK, Shift и Note Repeat** показаны на схеме серыми: их обрабатывает прошивка, назначить на них действие нельзя (замер — docs/PROTOCOL.md §1).
- **82 системных действия**: громкость, мьют микрофона, медиа-стоп, окна (свернуть / развернуть / закрыть), виртуальные рабочие столы, блокировка системы, скриншот, панель эмодзи, проводник, скролл и зум колесом, отмена и повтор, буфер обмена (копировать / вставить / вырезать), набор текста, произвольный хоткей, запуск программы, открытие папки, открытие URL, яркость пэдов, яркость монитора; браузер (вкладки, назад/вперёд, обновить, масштаб), Пуск / поиск / «Выполнить» / Параметры, история буфера, смена раскладки, погасить мониторы. На пэде с «Своей комбинацией» пишется сама комбинация, например `Ctrl+Shift+S`.

## Стек и архитектура
- **Язык**: Python 3
- **Библиотеки**: `tkinter` + `customtkinter` (GUI; схема устройства на чистом Tk, шапка и панель — CTk), `bleak` (BLE GATT), `pynput` (симуляция клавиатуры и мыши), `pycaw` + `comtypes` (системная громкость и мьют микрофона через `IAudioEndpointVolume`), `pystray` + `Pillow` (значок в трее), `asyncio`.
- **Архитектура**:
  - Main thread: `tkinter` mainloop (GUI).
  - Daemon thread: `asyncio` event loop для работы `bleak` (чтение нотификаций, отправка команд).
  - Взаимодействие через потокобезопасные `queue.Queue`.

## Структура
- `midi_gui.py` — GUI, разбор входящих MIDI-событий, маппинг на действия, инспектор привязок.
- `mvave/ble.py` — подключение по Bluetooth LE, работа с GATT, отправка цветов на железо.
- `mvave/protocol.py` — разбор и сборка вендорных пакетов устройства.
- `mvave/actions.py` — реестр системных действий и их исполнение.
- `mvave/appconfig.py` — чтение и атомарная запись `midi_config.json`.
- `mvave/volume_osd.py` — индикатор громкости в стиле флайаута Windows 11.
- `mvave/dimtray.py` — яркость монитора через DimTray по именованному каналу.
- `mvave/autostart.py` — автозапуск (реестр `HKCU\...\Run`) и ярлык на рабочем столе.
- `mvave/aa_shapes.py` — сглаженные скругления CustomTkinter (подмена кругов-символов картинками).
- `mvave/knob_art.py` — кадры крутилки. `mvave/winplace.py` — рабочая область и проверка места окна.
- `mvave/help_text.py` — текст справки.
- `mvave/tray.py` — значок в трее (pystray, свой поток; команды в GUI идут через очередь).
- `mvave/theme.py` — две палитры (тёмная, светлая), шрифты, стиль списка действий.
- `mvave/dialogs.py` — свои окна: тост, сообщение, вопрос, ввод, меню, выбор цвета.
- `mvave/presets.py` — пресеты в папке `presets/`.
- `tests/` — `smoke_ui.py` (дымовой прогон интерфейса), `test_config.py`, `test_protocol.py`.
- `tools/` — `build_exe.py` (сборка `release/SMC-PAD.exe`), `make_icon.py`, `probe_color.py`, `smoke_vendor.py`: вспомогательные утилиты, не часть приложения.
- `docs/PROTOCOL.md` — описание протокола устройства.
- `midi_config.json` — сохранённые привязки, создаётся приложением. В git не хранится: там личные пути владельца.
- `requirements.txt` — зависимости.
- `create_shortcut.vbs` — создаёт ярлык на рабочем столе; путь вычисляет от собственного расположения.
- `mvave_icon.ico` — иконка приложения.
- `LICENSE` — MIT.

## Как запустить

**Без Python.** Скачать `SMC-PAD.exe` из [Releases](https://github.com/eivl10/mvave-smc-pad/releases), положить в любую папку, запустить. Настройки программа хранит рядом с собой (`midi_config.json`), поэтому папка должна быть доступна на запись. Перенести настройки со старого компьютера: «Настройки → Загрузить настройки из файла…».

Собрать exe самому: `pip install pyinstaller`, затем `python tools/build_exe.py`.

**Из исходников:**
1. Поставить зависимости: `pip install -r requirements.txt`.
1. Убедиться, что M-Vave SMC-PAD включён и Bluetooth на ПК активен.
2. Запустить `midi_gui.py` напрямую или через ярлык на рабочем столе (`create_shortcut.vbs` его создаёт или обновляет).
3. Программа найдёт контроллер по имени `SMC-PAD` и начнёт принимать команды. Чтобы не сканировать эфир при каждом запуске, можно вписать адрес в `midi_config.json` ключом `"ble_address"`. Запуск через `pythonw` — без консольного окна.

Тесты запускаются из корня проекта; дымовой прогон интерфейса — `tests/smoke_ui.py`.
